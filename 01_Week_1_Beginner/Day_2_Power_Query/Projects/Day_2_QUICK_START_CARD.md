## 🔑 KEY CONCEPTS

### Power Query vs DAX
```
Power Query = Clean data before analysis
DAX = Calculate insights after loading
```

### The 80/20 Rule
```
80% of BI work = Data cleaning
20% = Visualization & analysis
Power Query automates the 80%!
```

### Applied Steps
```
Source (raw)
  ↓ (Step 1: Remove Dupes)
  ↓ (Step 2: Remove Blanks)
  ↓ (Step 3: Change Type)
  ↓ (Step 4: Replace Values)
Final (clean)
→ Click any step to see data at that point!
```

## 🎯 COMMON TRANSFORMATIONS

| Problem | Solution |
|---------|----------|
| Same row appears twice | Remove Duplicates |
| Empty rows | Remove Blank Rows |
| "2024-01-15" stored as text | Change Type → Date |
| "JOHN", "john", "John" | Text.Proper() |
| "N/A" values | Replace Values |
| "FirstName LastName" | Split Column |

---

## ⚡ POWER QUERY WORKFLOW

```
1. Get Data (load raw)
     ↓
2. Edit Query (Power Query Editor opens)
     ↓
3. Apply Transformations
     ├─ Remove issues
     ├─ Change types
     ├─ Split/merge
     └─ Create columns
     ↓
4. Close & Apply (load clean data)
     ↓
5. Use in Power BI
```

---

## 💡 KEY SHORTCUTS

| Action | How |
|--------|-----|
| Open Editor | Right-click table → Edit query |
| Remove Dupes | Home → Remove Duplicates |
| Remove Blanks | Home → Remove Rows → Blank Rows |
| Change Type | Click column → Home → Data Type |
| Replace Value | Home → Replace Values |
| Split Column | Column → Transform → Split |
| Load Changes | Close & Apply |

## ❌ COMMON MISTAKES

❌ **Clean in Excel first**
→ Power Query does it faster!

❌ **Delete source data**
→ Keep original for auditing

❌ **Guess what data means**
→ Ask if unsure!

❌ **Overwhelm with steps**
→ One transformation at a time

❌ **Forget to save**
→ Save frequently!

---

## ✅ BEST PRACTICES

✅ **Load raw data first** - Power Query cleans it
✅ **Document assumptions** - Why did you remove rows?
✅ **Test on sample** - Try transformation on small data
✅ **Reuse queries** - Save for next week's data
✅ **Save often** - Don't lose work!
