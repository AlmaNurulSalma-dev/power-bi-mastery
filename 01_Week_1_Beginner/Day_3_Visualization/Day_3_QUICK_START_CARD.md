## 📊 5 CHARTS TO CREATE

### Chart 1: Column Chart
```
Title: "Total Sales by Store"
X-axis: store_id
Y-axis: Sum of list_price
Format: Blue bars, data labels ON
```

### Chart 2: Bar Chart
```
Title: "Top 10 Products by Revenue"
X-axis: product_id
Y-axis: Sum of list_price
Format: Sorted descending, top 10 only
```

### Chart 3: Pie Chart
```
Title: "Sales Distribution by Gender"
Legend: gender
Values: Sum of list_price
Format: Percentages, not red+green colors
```

### Chart 4: Line Chart
```
Title: "Sales Trend Over Time"
X-axis: transaction_year
Y-axis: Sum of list_price
Format: Blue line, data labels ON
```

### Chart 5: Donut Chart
```
Title: "Sales by Age Segment"
Legend: age_segment
Values: Sum of list_price
Format: Center shows total, % labels
```

### Slicer 2: Gender
```

### Slicer 3: Year Range
```

Position: Top-right

## 🔧 QUICK COMMANDS

**Insert Chart:**
```
Insert tab → [Chart type]
```

**Add Slicer:**
```
Insert tab → Slicer → [Choose field]
```

**Connect Slicer:**
```
Click chart → Format → Edit Interactions
Choose slicer → Enable filter
```

**Format Colors:**
```
Click chart → Format panel (paint bucket)
Data colors → Change color
```
