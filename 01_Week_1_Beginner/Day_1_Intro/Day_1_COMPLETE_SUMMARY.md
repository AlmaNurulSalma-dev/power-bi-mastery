## 🚦 TROUBLESHOOTING QUICK REFERENCE

| Problem | Solution |
|---------|----------|
| Power BI won't install | Restart PC, try as Administrator |
| Sample data missing | File → Options → Download sample |
| Chart appears blank | Check fields in Visualizations panel |
| Slicer doesn't filter | Ensure chart & slicer on same page |
| Can't find a button | Check different tabs in ribbon |
| File won't save | Try Save As, check folder permissions |
