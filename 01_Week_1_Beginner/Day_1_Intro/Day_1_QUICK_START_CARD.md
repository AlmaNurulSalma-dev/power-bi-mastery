## 🎮 HANDS-ON GUIDE (120 minutes)

### TASK 1: Load Sample Data (20-30 min)
```
1. Open Power BI → File → Samples → Retail Analysis Sample
2. Explore the 4 report pages
3. Check the Fields panel (right side)
4. Take screenshot
5. Save screenshot to: Day_1_Intro/Day_1_Task_1_Screenshot.png
```

✅ Success = Loaded data + explored pages

---

### TASK 2: Create First Visual (30-40 min)
```
1. Create new blank page (+ icon at bottom)
2. Insert Column Chart (Insert tab)
3. Add Category → Axis
4. Add Amount → Values
5. Change title to "Sales by Category"
6. Insert Card visual
7. Add Amount to Card
8. Save as: Day_1_First_Report.pbix
```

✅ Success = Chart shows data + Card shows total

---

### TASK 3: Add Interactivity (40-50 min)
```
1. Insert Slicer (Insert tab)
2. Add Region field to slicer
3. Click region → Chart filters! ✨
4. Insert another Slicer
5. Add Category field
6. Test both together
7. Save file
```

✅ Success = Both slicers filter chart in real-time

## 🎓 KEY CONCEPTS GLOSSARY

| Term | Simple Definition |
|------|-------------------|
| **DAX** | Excel-like formulas for Power BI |
| **Measure** | A calculation (like SUM, AVERAGE) |
| **Dimension** | A descriptor (Region, Product, Date) |
| **Relationship** | Connection between tables |
| **Slicer** | Interactive filter button |
| **Fact table** | Table with transactions/numbers |
| **Power Query** | Data cleaning tool |
| **PBIX** | Power BI file format |
